# Constitución del Proyecto: Roadmap y Mejoras Futuras

Este documento define la planificación oficial de las funcionalidades y mejoras en el portafolio bajo Spec-Driven Development (SDD).

## Prioridades y Especificaciones Activas

### 1. SPEC-006: Sincronización de Pipeline CI/CD y Verificación Local (P0)

- **Estado**: ✅ Completado.
- **Detalle**: Unificación de scripts (`scripts/loop-verify.js`) y workflows de GitHub Actions para Next.js 16.

### 2. SPEC-005: Blindaje Anti-Spam en Formulario de Contacto (P0)

- **Estado**: ✅ Completado.
- **Detalle**: Integración de campo honeypot invisible, debounce y protección de endpoint.

### 3. SPEC-001: Limpieza y Consolidación de Componentes Huérfanos (P1)

- **Estado**: ✅ Completado.
- **Detalle**: Desacople de `reactflow`, eliminación de código muerto e integración modular de `TimelineItem.tsx`.

### 4. SPEC-002: Sistema de Internacionalización (i18n ES / EN) (P1)

- **Estado**: ✅ Completado.
- **Detalle**: Conmutación de idioma en tiempo real para interfaz web y CV en PDF.

### 5. SPEC-003: Terminal Extendida & Comandos de Sistema (P2)

- **Estado**: ✅ Completado.
- **Detalle**: Comandos interactivos (`theme`, `cv`, `lang`, `clear`, `history`) y soporte táctil móvil.

### 6. SPEC-004: Minijuego RPG 2D Embebido (P2)

- **Estado**: Pendiente.
- **Detalle**: Simulación interactiva de hangar y agentes virtuales en Canvas pixel-art.
