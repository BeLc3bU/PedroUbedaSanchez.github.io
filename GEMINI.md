# Directrices de Antigravity para PedroUbedaSanchez.github.io (EGM + ODD)

- **Estándar Integrado:**
    - **Elephant-Goldfish Model (EGM):** Diseño arquitectónico con contexto (`/egm-brainstorm`, `/egm-draft` en `docs/designs/`), revisión crítica sin sesgo con contexto cero (`/egm-review`), y control de deriva (`/egm-drift-report`).
    - **Organic-Driven Development (ODD) — Gentle Shell:** Implementación orgánica, TDD determinista (RED -> GREEN -> REFACTOR) y seguimiento en `odd/tasks/<feature>.md`.
- **Commits:** Work-Unit Commits de ~400 líneas uniendo código + test + docs (Conventional Commits en español).
- **Pruebas:** Ejecutar `npm run test` tras cualquier modificación.
- **Idioma:** Español obligatorio.
